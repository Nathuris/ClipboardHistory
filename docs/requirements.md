# 开发需求规格

## 项目名称

ClipboardHistory — Mac 历史剪贴板

## 项目简介

一款运行在 macOS 上的剪贴板历史管理软件。自动记录用户复制的文字和图片，支持搜索、置顶、删除，可设定保留天数，并具备隐私保护功能。

## 目标用户

- Mac 日常用户
- 对电脑操作不熟悉的小白用户
- 需要频繁查找历史复制内容的办公用户

## 功能需求

### F1 — 剪贴板自动监听

- 软件在后台自动运行，实时监听系统剪贴板变化
- 支持记录**文字**内容
- 支持记录**图片**内容（PNG、JPG、GIF 等常见格式）
- 记录每条内容的**来源 App**（如 Safari、Notes、微信等）
- **去重**：连续复制同一内容不重复记录

### F2 — 历史记录查看

- 以**时间降序**排列（最新复制的在最上面）
- 每条记录以**卡片**形式展示
- 卡片显示内容：
  - 来源 App 图标 + 名称
  - 复制时间（相对时间，如"3 分钟前"）
  - 内容预览（文字截取前 100 字符，图片显示缩略图）
  - 置顶按钮
  - 删除按钮

### F3 — 粘贴功能

- 点击卡片 → 将该条内容写回系统剪贴板
- 写回后面板自动收起
- 用户可在任意 App 中使用 Cmd+V 粘贴

### F4 — 置顶功能

- 重要内容可**置顶**
- 置顶内容始终排列在列表最上方
- 支持取消置顶

### F5 — 删除功能

- 可删除不需要的历史记录
- 删除时弹出确认提示，防止误删

### F6 — 搜索功能

- 在面板顶部提供搜索框
- **实时搜索**：输入即过滤，无需按回车
- 搜索范围：文字内容
- 搜索结果保持排序规则（置顶优先 + 时间倒序）

### F7 — 保留天数设置

- 用户可选择保留天数：**1 天 / 3 天 / 5 天**
- 超过保留天数的非置顶内容自动清理
- 置顶内容永不过期

### F8 — 菜单栏运行

- 软件以**菜单栏图标**形式运行（不占用 Dock 空间）
- 点击图标弹出历史面板
- 点击面板外部区域自动收起

### F9 — 全局快捷键

- 默认快捷键：**Command + Shift + V**
- 按下快捷键直接弹出/收起历史面板
- 用户可自定义快捷键组合

### F10 — 开机自启

- 软件可设置为开机自动启动
- 首次启动时询问用户是否开启
- 可在设置中随时开关

### F11 — 隐私保护（黑名单 + Touch ID）

- 用户可设置**黑名单 App 列表**
- 从黑名单 App 复制的内容：
  - **加密存储**在本地数据库中
  - 在面板中显示为**锁定遮罩卡片**（不显示内容预览）
  - 点击查看时触发 **Touch ID 或 Mac 登录密码**验证
  - 验证通过 → 解密 → 可粘贴
  - 验证失败 → 拒绝访问

### F12 — 设置窗口

- 独立的设置窗口，包含：
  - 通用：保留天数选择
  - 快捷键：录制自定义快捷键
  - 隐私：黑名单 App 管理
  - 关于：软件版本信息

## 非功能需求

- **性能**：面板打开流畅，列表滚动不卡顿（即使有上千条记录）
- **存储**：图片存储空间合理控制，随过期清理同步删除
- **隐私**：所有数据仅存储在本地，不上传网络
- **权限**：首次启动引导用户授予辅助功能权限
- **兼容性**：支持 macOS 14 (Sonoma) 及以上版本
- **UI 适配**：适配 macOS 深色模式 / 浅色模式

## 优先级

| 优先级 | 功能 |
|--------|------|
| P0（必须有） | F1 剪贴板监听、F2 历史查看、F3 粘贴 |
| P1（核心体验） | F6 搜索、F7 保留天数、F8 菜单栏 |
| P2（增强体验） | F4 置顶、F5 删除、F9 快捷键、F10 开机自启 |
| P3（进阶功能） | F11 隐私保护、F12 设置窗口 |

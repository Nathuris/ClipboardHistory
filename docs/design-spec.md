# UI 设计规范

## 设计原则

- **简洁**：减少视觉噪音，突出内容本身
- **直观**：不需要学习成本，一看就知道怎么用
- **一致**：遵循 macOS 原生设计语言（HIG）
- **轻盈**：以淡蓝色为主色调，营造清爽感

## 图标规格

### 菜单栏图标

- 格式：PDF (矢量)，适配任意尺寸
- 实际渲染尺寸：18×18pt（菜单栏标准）
- 设计：剪贴板/剪贴符号，使用主蓝色
- 深色模式：自动切换浅色版本

### App 图标

- 格式：icns（多尺寸）
- 设计：圆角方形，主蓝背景 + 白色剪贴板图标
- 尺寸：16/32/64/128/256/512/1024px

### SF Symbols（系统图标）

所有 UI 图标优先使用 Apple SF Symbols，确保原生观感：

| 用途 | SF Symbol 名称 |
|------|---------------|
| 搜索 | `magnifyingglass` |
| 设置 | `gearshape` |
| 置顶 | `pin.fill` |
| 取消置顶 | `pin.slash` |
| 删除 | `trash` |
| 关闭 | `xmark` |
| 复制 | `doc.on.doc` |
| 锁定 | `lock.fill` |
| 解锁 | `lock.open` |
| 图片占位 | `photo` |
| 文字占位 | `doc.text` |

## 动效规范

| 动效 | 时长 | 说明 |
|------|------|------|
| 面板弹出 | 0.15s | 从菜单栏向下展开，easeOut |
| 面板收起 | 0.1s | 向上收起，easeIn |
| 卡片出现 | 0.2s | 淡入 + 微上移 4pt |
| 卡片删除 | 0.2s | 淡出 + 右滑，easeIn |
| 搜索过滤 | 0.15s | 交叉淡入淡出 |
| Touch ID 弹窗 | 系统默认 | 使用系统原生动画 |
